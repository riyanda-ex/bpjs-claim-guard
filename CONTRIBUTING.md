# Kontribusi

## Aturan
1. Jangan upload data klaim BPJS asli (nama pasien, NIK, No. SEP, No. Kartu BPJS, PDF SEP).
2. Gunakan ID anonim: `KLAIM-001`, bukan data asli.
3. Semua perubahan aturan harus lolos `python test.py` - wajib 10/10.
4. Satu PR untuk satu fitur / perbaikan.

## Cara
1. Fork repo ini
2. Buat branch: `git checkout -b tambah-aturan`
3. Jalankan test: `python test.py`
4. Buat Pull Request dengan deskripsi jelas
